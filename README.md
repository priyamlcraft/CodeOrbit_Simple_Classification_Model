# CodeOrbit Task 2: Simple Classification Model

## Project Overview
This project builds a simple Machine Learning classification model using Python and Scikit-learn. The Iris dataset is used to classify iris flowers into three species based on their measurements.

## Objectives
- Load and explore the Iris dataset.
- Split the data into training and testing sets.
- Apply feature scaling.
- Train a Logistic Regression classification model.
- Evaluate the model using performance metrics.
- Visualize results using a confusion matrix.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Scikit-learn

## Dataset
The project uses the Iris dataset available directly from Scikit-learn. It contains flower measurements and three target classes.

## Project Workflow
1. Load the Iris dataset.
2. Prepare the features and target labels.
3. Split the dataset into training and testing sets.
4. Scale features and train the Logistic Regression model.
5. Generate predictions.
6. Evaluate performance using accuracy, precision, recall, and a classification report.
7. Generate and save a confusion matrix plot.

## Installation
Install the required libraries:

```bash
python -m pip install -r requirements.txt
```

## How to Run
Run the following command in the project folder:

```bash
python CodeOrbit_Task_2_Simple_Classification_Model.py
```

## Output
The program displays model evaluation metrics and sample predictions. It also saves a confusion matrix image named `confusion_matrix.png`.

- Training a Logistic Regression model.
- Evaluating classification performance.
